# Audio sources — 0.7.0

island-loop.wav and heal/defeat/skill/kill.wav: original simple synthesized melody and effects generated for this project, using work/audio-070.py. No external song sampled or downloaded.
kill-1.wav through kill-5.wav: English text synthesized locally with installed Microsoft David Desktop voice, using System.Speech. Phrases: One kill; Two kills; Three kills; Four kills; Five kills. These are rendered audio assets, not a runtime dependency on Windows speech.

Optional future source: https://kenney.nl/assets/category:Audio (Kenney support states assets on asset pages are CC0: https://kenney.nl/support). No Kenney asset is bundled in this release. Incompetech also offers music under attribution licenses; check the chosen track license before replacement.

0.7.1: pentakill.wav is a new local Microsoft David Desktop rendering of "Pentakill", replacing kill-5.wav at runtime. The old voice file is unused.
